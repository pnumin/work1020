# 국방예산 분야별 · 신규사업 대시보드 & 인터랙티브 인포그래픽

첨부해주신 엑셀(`.xlsx`, `.xls`) 및 CSV(`.csv`) 데이터를 업로드하면 **분야별(중점영역)** 및 **신규사업별** 핵심 지표를 실시간으로 분석·시각화해 주는 반응형 웹 대시보드입니다.

---

## 🎯 신규 기능: 분야 & 신규사업 선택 연동 인터랙티브 인포그래픽

상단 컨트롤 바에서 **분야(중점영역)** 또는 **신규사업** 버튼을 클릭하면, 하단의 대형 인포그래픽 보드가 선택한 대상에 맞춰 실시간으로 동적 전환됩니다!

1. **분야(중점영역) 선택 시**:
   - 해당 중점영역의 2027년 정부안 총액 및 전년 대비 증감액/증감율 비주얼 카드
   - 전체 국방예산 대비 점유 비중 게이지 & 분야 내 신규사업 투자 비중 게이지
   - 국방부 대표 보도자료 박스 원문 근거 인포그래픽
   - 해당 분야에 포함된 세부사업 파이프라인 칩 (신규사업 뱃지 및 사업별 예산 표출)

2. **신규사업(✨) 선택 시**:
   - 해당 신규사업의 2027년 신규 편성 예산 대형 수치 지표 (Big Stat)
   - 소속 분야 내 점유율 및 전체 신규사업 예산 대비 비중 게이지
   - **국방부 보도자료 원문 박스 근거 인포그래픽** 전문 표출
   - 3대 핵심 분석 카드 (소속 중점 영역, 편성 성격, 정책 기대 효과)
   - 원클릭 상세 원문 팝업 모달 연계

3. **신규사업 총괄 개괄 선택 시**:
   - 2027년도 10개 핵심 신규과제의 총 예산 규모(1,495억원) 및 3대 투자 방향성 인포그래픽 요약

---

## 🚀 빠른 시작 방법

1. **원클릭 실행**:
   - 폴더 내 `대시보드_실행.bat` 더블클릭, 또는 `web/index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 열기
2. **별도 서버 불필요**:
   - 인터넷 브라우저 자체에서 엑셀 및 CSV를 즉시 파싱하며 오프라인에서도 기본 데이터로 동작합니다.
